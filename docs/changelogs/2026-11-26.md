### fix：启用平台原生钥匙串后端并修复三方模型 API Key 丢失导致的 401

- 根因：`keyring = "3"` 未声明平台后端 feature，macOS 静默退回内存 mock，每次 `Entry::new` 都是空存储，`set_password` 看似成功但重启/另一次读取必然 `NoEntry`，请求因此不带 Authorization 被上游判为 401
- Cargo.toml 按目标平台显式启用 `apple-native` / `windows-native` / `linux-native`，密钥现在真正写入系统钥匙串；Cargo.lock 同步更新
- 后端严格区分「未配置密钥」与「引用失效」：引用存在但钥匙串读不到时直接报本地校验错误，不再裸发无鉴权请求
- 新增 `keychain_has` 命令（只回布尔值、不取明文），编辑弹窗打开时核对真实存储状态，失效显示「密钥引用失效，请重新填入」而非绿色「已保存密钥」
- 验证：Rust 172 例、前端 138 例、typecheck / check / conventions / build 全绿
