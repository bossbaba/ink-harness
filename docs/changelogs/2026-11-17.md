### P4-1：写作台（ca80082）

**后端（Rust）**

- `chapter` 表新增 `content`（TipTap 文档 JSON）与 `word_count`（非空白字符数），`draft_version` 表新增 `word_count`；三列都走 `ensure_column` 迁移，老库自动补齐。
- `models/draft.rs`：`ChapterContent / SaveContentInput / DraftVersionBrief / DraftVersion`。
- `services/draft.rs`：正文读写、版本快照、恢复。首次写入有内容时把章节从 `planned` 推进到 `drafting`；自动保存仅在字数差 ≥ 500 时留版，手动「保存快照」内容未变则不重复留版；恢复前先把当前正文补成底稿（已有同内容快照则跳过）；每章版本上限 50，超出删最旧。
- `Chapter` 增加 `word_count`，章节列表直接带字数，不额外拉正文。
- 新增 7 项单测：首次落笔推进状态并留底稿、自动保存按阈值留版、手动快照去重、恢复回滚、恢复前补底稿、版本裁剪、缺章与负字数校验。

**前端（Vue 3 + TypeScript）**

- 新增依赖 `@tiptap/vue-3`、`@tiptap/starter-kit`、`@tiptap/extension-placeholder`（TipTap 2.27）。
- 新增作品内页面 `/projects/:projectId/write/:chapterId?`（路由名 `project-writing`）：左侧三幕章节列表（状态 + 字数）、中间 TipTap 编辑器（加粗/倾斜/删除线/H2/引用/列表/撤销重做）、右侧抽屉式版本快照。
- 没有 `chapterId` 时不自动选中第一章，页面只提示选章并给出「去大纲创建章节」入口；章节切换、版本恢复靠 `:key` 重建编辑器，撤销栈与选区不串章。
- `useWritingDesk`：章节 id 变化先 flush 再载入；自动保存 1.2s 防抖，切章/隐藏窗口/卸载时立即落盘；保存只认「已载入正文的章节 id」，避免切章瞬间把上一章内容写进新章节。
- 字数口径统一在 `utils/text.ts` 的 `countCharacters`（去空白后按字符计数），保存后同步更新章节列表字数。
- 接入导航：作品内二级导航开放「写作台」，工作台作品卡片新增「进入写作台 →」。

**验证结果**

- Rust：`cargo test` 41 例通过（36 单元 + 2 双连接 + 3 vec）；`cargo clippy --all-targets` 无新增告警。
- 前端：`vue-tsc --noEmit`、`biome check`、`pnpm build` 均通过；顺带修掉 `WorkspaceView` 的 `line-clamp` 标准属性告警与 `useIdeationWizard` 的导入排序错误。

- 新增 7 项单测：默认种子、删除后不复种、CRUD 往返、字段校验、地址归一化、响应解析、探测 HTTP 回退（本地 TcpListener 模拟 404 → 200）。

**前端（Vue 3 + TypeScript）**

- 新增 `/models` 模型管理页：Provider 按本地/云端分组、启用开关、测试连接、本地一键「同步模型」、删除（同时清理钥匙串）。
- Provider 编辑弹窗：名称/来源/地址/API Key（密码框，可清除已存密钥）、测试连接并拉取模型、逐模型勾选与上下文窗口设置。

### 初始提交：项目骨架与核心功能首版

**项目定位**

INK-HARNESS 是本地优先的 AI 辅助写作桌面软件，覆盖构思 → 设定 → 初稿 → 编辑 → 出版的全链路，人在环路（human-in-the-loop），上下文沉淀到统一的「作品记忆库（Story Bible）」。

**前端（Vue 3 + TypeScript + Vite 7）**

- 应用外壳 `AppShell` 与工作台 `WorkspaceView`、全局设定库 `GlobalBibleView`、作品设定库 `ProjectBibleView`、作品外壳 `ProjectShellView`。
- 故事设定库组件（列表 / 新建弹窗 / 表单 / 洞察面板）、关系图 `RelationGraph`、新建作品弹窗。
- composables：`useGlobalBible` / `useStoryBible`，显式区分全局与作品作用域。
- services：`modelRouter`、`projectService`、`storyElementService`；Pinia 状态 `stores/app`。
- 设计令牌单一真源 `src/styles/_tokens.scss` 与 `src/theme/palette.ts`，语义化 CSS 变量。

**后端（Rust + Tauri 2）**

- commands：`model` / `ollama` / `keychain` / `project` / `story_element`，覆盖 Provider 配置、模型对话、系统钥匙串、作品与设定 CRUD、一致性校验。
- infrastructure：SQLite（含 sqlite-vec 向量扩展）、keychain、`llm_http`（本地 / 三方模型统一接入）。
- models：chat / project / provider / story_element；services：gateway / ollama / project / story_element。
- 入口 `lib.rs` 注册全部命令，管理 `GatewayState` 与数据库状态。

**工程与规范**

- pnpm workspace + biome 代码规范；Tauri 2 配置与多平台图标资源。
- `.codebuddy/rules` 下四条项目规则：代码注释、功能页面唯一性、项目通用约定、UI 样式一致性。

**验证结果**

- Rust 单测：19 例全部通过（14 单元 + 2 双连接 spike + 3 vec spike）。
- 前端类型检查：`vue-tsc --noEmit` 通过。
