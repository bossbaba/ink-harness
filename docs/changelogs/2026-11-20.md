## 更新内容

### busy 按动作拆分到按钮粒度，行级删除与预览补独立 loading

- 现象：多个操作共用一个 busy，A 操作进行时 B 按钮也跟着转圈或被禁用，反馈指向错误；部分异步按钮（行级删除、版本预览）完全没有 loading。
- 拆分：`useStoryBible` 拆成 `saving` / `creating` / `removing` / `checking`，`busy` 改为并集只用于禁用其余入口；版本面板补 `previewBusy`；大纲与 Provider 各补 `removingId`。
- 行级反馈：章节/场景/伏笔/Provider 的删除按钮只让被点的那行转圈，其余按钮禁用；看板新增入口在写操作期间禁用，避免与删除交错。
- 工作流补 `anyRunning`：任一阶段生成时其余阶段的运行按钮禁用——`run()` 对非本阶段的调用直接 return，此前点了毫无反馈。
- 修正：编辑审稿「开始审读」撤回 `:loading`——该 loading 是页面数据加载而非按钮自身动作，转圈有误导，改回仅 `:disabled="!canRun"`；新建作品弹窗取消按钮在创建期间禁用，防止中途关窗。
- 验证：`pnpm typecheck`、`pnpm check`、39 单测、`pnpm build` 全绿。

### 打印 loading 守卫与 biome 插件模式

- `useProjectPublish.printPdf` 与导出共用 `exporting` 状态：读正文 + 起 iframe 期间按钮转圈，并挡住重复点击；`finally` 里复位，读正文提前返回也不会卡死按钮。
- `vite.config.ts` 的 biome 插件从 `mode: "format"` 改为 `mode: "check"`：热更新只做检查不静默改写文件，避免开发时源码被插件悄悄重排。
- 验证：`pnpm check:all`（39 单测、规范 171+66 文件）全绿。

### 页面级空状态升级

- 现象：页面空状态直接摆 NEmpty 的小图标加一行灰字，第一眼像「没加载出来」而不是「这里等着你开始」，观感小气。
- 实现：新增共享组件 `AppEmpty`（44px 主色徽章图标 + 标题 + 说明 + 行动按钮），颜色/圆角/间距全部取设计令牌，总高 ≤220px 符合空状态规范。替换六处页面级空状态：工作台「我的作品」、全局设定库主面板、全局统计无作品、Agent 运行轨迹（行动入口经 props/emit 由父页处理）、编辑审稿占位（按钮直连 `startReview`）、出版中心无正文（跳写作台）。
- 统一：`WritingEmptyState` 改为复用 `AppEmpty`，写作台「未选章 / 正文载入失败」两处视觉随之对齐；分层保持组件不直接走路由，跳转分别落在 `useGlobalBible.goWorkspace` 与各视图的 `useRouter`。
- 边界：弹窗、列表分组、筛选无结果等密集场景仍用小号 NEmpty，不套大状态。
- 验证：`pnpm check:all`（39 单测、规范 171+66 文件）全绿。

### propose_review 工具补齐 P1 首批清单

- 背景：方案文档 P1 首批 6 工具含「生成审稿建议」，此前被 `inspect_element` 顶替。
- 实现：`agentTools` 新增 `propose_review`（read 级）——读作品/章节/上下文 → `runChat(task: "review")` → `parseReviewIssues` 解析 → 按「级别·层级」中文标签输出清单；解析失败回传原文。隐私范围直接读作品配置，不依赖调用方传参，避免漏传把本地作品发去云端；降级轨提示词同步收录该工具。

### 轨迹按模型折算成本

- 步骤明细行同时展示模型，便于排查「换模型后效果变化」。

### db.rs 拆分与 ensure_column 表存在性守卫

- 迁移逻辑（SCHEMA_VERSION / migrate / create_agent_tables / backfill_columns / ensure_column）拆到 `infrastructure/db/schema.rs`（287 行），`db.rs` 降到 273 行，均满足 ≤500 行规范。
- `ensure_column` 先查 `sqlite_master`：`pragma table_info` 对不存在的表返回空结果，会误判成「缺列」，随后 `alter` 报 `no such table`——backfill 在建表迁移之前执行时正好踩中（本次 63 个测试失败的根因）。
- 验证：`pnpm check:all`（39 单测、规范 170+66 文件）、`cargo test`（120 lib + 集成含 IPC 契约）全绿。

### 章节摘要弹窗过宽

- 现象：章节摘要弹窗几乎撑满整个窗口，摘要正文一行拉到上千像素，难以阅读。
- 修复：`ChapterSummaryDialog` 的 NModal 补上项目统一的 `:style="{ width: '640px', maxWidth: 'calc(100vw - 48px)' }"`，与新建作品、Provider 编辑、作品上下文等弹窗同款约束；640px 比新建作品的 560px 稍宽，给摘要长文本留出阅读行宽。
- 验证：`pnpm typecheck`、`pnpm check` 通过。

### Agent 轨迹真实记账（tokens / 耗时）

- 现象：轨迹面板每轮显示 `0 tokens · 0 ms`——网关在 Rust 侧收到用量后只写 `agent_run`，从未透传前端，`agent_step` 的 tokens/latency 落库时恒为 0。
- 修复：`ChatChunk` 新增 `usage` 字段，用量事件到达时独立推一块给前端；`ChatRunResult` 带回 `usage`；`agentLoop` 每轮测量耗时并把 `tokens`/`latencyMs` 记入 `AgentStep`，`useWritingCopilot` 落库时写入真实值。
- 验证：新增单测锁「有用量记 30、无用量记 0、耗时非负」；`pnpm check:all`（39 单测）、`cargo test`（120 lib + 集成）全绿。

### 关闭重开后可继续历史会话（P3 验收项）

- 现象：`list_messages` 前后端早已实现但 UI 从未调用，重开应用后 Copilot 历史丢失，无法继续会话。
