## 更新内容

### 审稿 Diff 逐条应用与批注（P5-2）

- `ReviewIssue` 增加 `replacement`（能直接替换 `quote` 的正文）与 `comment` / `decision`，和原来的 `suggestion` 说明分开；模型提示要求 `replacement` 只含替换后的字句，结构性问题留空，旧模型不输出时按空串处理。
- 新增字符级 Diff 工具 `utils/textDiff.ts`：按 Unicode 码点做 LCS，删红加删除线、增绿加粗；超过 600 字直接整段替换，避免长文把界面卡住。
- 审稿卡片支持逐条「接受 / 忽略 / 再点一次回到待定」与批注输入，决定和批注随 Markdown 报告一起复制；写回正文后条目变 `applied` 终态，不再改动。
- 新增 `services/reviewApply.ts`：按段落把纯文本替换定位回 TipTap 文档 JSON，先找单个文本节点、再在同一段相邻节点拼接后找；定位失败列入失败项提示手工改，不猜位置。
- 「应用 N 处修改」只处理本章 + 已采纳 + 有原文与替换文本的条目，保存时 `snapshot: true` 留整批回退点；全书概览没有正文，只做批注与复制。
- 新增 `stores/draftSync.ts` 记录章节正文版本：写作台从 keep-alive 缓存回来时比对，版本变了就丢弃旧稿重读，避免自动保存把审稿结果覆盖掉。

### 出版中心（P6）

- 新增作品内路由 `/projects/:projectId/publish`（`project-publish`），接入侧栏二级导航与工作台作品卡片；全局侧栏同名项保持禁用——出版属于某部作品，不提供全局汇总页。
- 页面分四区：排版预览、导出、发布物料、发布清单；三套排版模板（网络连载 / 电子书 / 纸质稿）只换 CSS，用 `iframe srcdoc` 看版式，另有 Markdown 源码视图与复制。
- 新增 `utils/zip.ts`：自写 store 模式 ZIP（无需压缩库，`mimetype` 排第一且未压缩），据此在前端生成 EPUB 3（container.xml / content.opf / nav.xhtml / 章节 xhtml）与 DOCX（最小 OpenXML）；Markdown / HTML 直接写文本。
- 保存位置由 `@tauri-apps/plugin-dialog` 原生对话框选；Rust 新增命令 `write_export_file` 只负责把字节落盘，不配 fs scope、内容不上传。Cargo 增加 dialog 插件并提升 rust-version 到 1.90，capabilities 增加 `dialog:allow-save`。
- PDF 不自己嵌中文字体：把当前模板 HTML 写进隐藏 iframe 后 `window.print()`，让用户在系统打印对话框里另存为 PDF。
- 新增 `TaskKind: publish`，一次请求生成简介 / 标签 / 封面需求简报 / 投稿信 JSON，可编辑可复制，解析失败保留原文，仍受作品 `privacy` 约束。
- 发布清单内置 6 个平台的口味提示，勾选平台并记录日期与备注，计划只存浏览器本地，不写进作品库、不代替投稿。
- 从写作台回到出版中心时 `onReactivated` 重读正文，预览与导出不会用旧稿。
