## 更新内容

### UI 现代化与大气化

- **配色与层次**：主色从荧光绿 `#00c100` 收敛为稳重翠绿（浅色 `#0f8f52` / 深色 `#3ddc91`），明暗主题的 CSS 变量与 Naive UI overrides 同步更新；新增 `--bg-elevated` / `--on-accent` 语义变量；卡片圆角 12→14px，新增 `$shadow-elevated` 两层抬升阴影，悬浮时更有纵深。
- **应用外壳**：标题栏 44→52px，品牌「墨」印改渐变 + 内高光；顶栏当前模型改为带状态圆点的主色胶囊，明确「正在生效」；侧栏导航项加高到 36px、选中态加左侧主色竖条，专注模式入口加分隔线；内容区顶部加淡主色环境光，与标题栏自然衔接。
- **共享组件**：新增 `PageHeader.vue`（眉标 / 标题 / 副标题 / 操作区）与 `StatCard.vue`（标签 / 数值 / 附属内容 / 操作区，支持强调态），收敛各页面重复的标题与指标卡样式；模型管理页、全局统计页已接入并删除各自的旧样式。
- **工作台首屏**：Hero 改为带主色环境光的面板，加眉标「INK-HARNESS · 创作工作台」与「本地优先 · 数据不上云」说明；区块标题加主色竖条；空状态补「新建作品」行动入口；作品卡片加悬浮抬升；运行状态卡改用统一指标卡，长句允许换行不再被截断。
- **验证结果**：所有改动文件 ≤ 500 行（AppShell 460、WorkspaceView 390、ModelSettingsView 422）；`pnpm typecheck`、`pnpm check`（160 文件）、`pnpm build` 均通过；浏览器截图核对浅色 / 深色主题与工作台、模型管理、统计三页，无横向溢出。

### 默认模型设置与顶栏当前模型标识

- 新增 `SETTING_DEFAULT_MODEL`（`default_model`）设置项。模型管理页「任务路由」增加「默认模型」下拉：候选为已启用 Provider 下的全部模型，值沿用 `providerId:modelId`，与 RAG 模型选项口径一致；清除后回到按策略自动选。
- `modelRouter` 的 `select()` 在打分前优先命中默认模型（仍需满足当次隐私与上下文窗口约束），否则回落原有质量 / 成本 / 隐私打分；`refresh()` 一并读取默认模型，改策略或改默认模型后立即重算 `currentModel` 并通知订阅者。
- 顶栏经 `useCurrentModel()` 读取 `modelRouter.currentModel`，展示可点击的当前模型 Tag；tooltip 给出本地 / 云端与模型 ID，点击跳转模型管理。`App.vue` 启动时主动 `refresh()` 一次，无需先进入模型管理页才有值。
- 已选默认模型若被删除或 Provider 停用，设置页给出提示并说明已暂时回落，避免静默按策略选模型而用户不知情。
- 为守住单文件 500 行上限，把模型管理页「任务路由」面板样式抽到 `src/styles/_model-routing.scss`，视图文件由 506 行降到 439 行；抽出的样式经构建验证仍带 scoped 选择器（`.routing__default[data-v-…]`）。
- 验证结果：`pnpm typecheck`、`pnpm check`（157 文件）、`pnpm build` 均通过；确认构建产物中 `.routing__default[data-v-…]` 等选择器作用域正确。
